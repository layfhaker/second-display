# Целевое железо

| Роль            | Устройство              | Важное для проекта |
|-----------------|-------------------------|--------------------|
| ПК (хост)       | ASUS Zenbook UX435E     | Intel Tiger Lake (11th gen), iGPU Iris Xe / UHD → **QuickSync** для H.264/HEVC. NVENC нет (даже если вариант с MX450 — слабый, ориентируемся на QuickSync). |
| Планшет (клиент)| OPPO Pad 3 Pro          | ~3.2K экран, высокий refresh, Snapdragon 8 Gen 3 → аппаратный декод H.264/**HEVC** не проблема. USB-C. |
| Карта захвата   | UGREEN CM489            | HDMI→USB-C UVC, до 4K@30 / 1080p@60. Делает вариант HDMI рабочим без драйвера. |
| Хаб             | UGREEN Revodok 45366    | USB-C хаб. Для ADB планшет лучше втыкать НАПРЯМУЮ в порт ноутбука, не через хаб. |

## Решения, вытекающие из железа

### Кодек на хосте → QuickSync (Media Foundation), НЕ NVENC
Zenbook на Intel iGPU. Кодим через Media Foundation H.264/HEVC encoder, который
маппится на QuickSync. HEVC даёт лучшее качество/битрейт — Pad 3 Pro его аппаратно декодит,
так что **HEVC предпочтителен**, H.264 как fallback.

### Разрешение/refresh — НЕ гнать нативные 3.2K@144
Нативное разрешение планшета × высокий refresh = огромный битрейт и нагрузка на iGPU-энкодер.
Старт: **1920×1200 @ 60 Гц** (близко к соотношению сторон Pad 3 Pro 3:2), потом поднимать.
Виртуальный дисплей (фаза 3) регистрируем именно с этим режимом, планшет апскейлит.

### Транспорт — USB/ADB остаётся приоритетом
- Pad 3 Pro поддерживает отладку по USB → ADB-туннель работает. Втыкать в ноут напрямую.
- HDMI-вариант через CM489 теперь реально доступен как **план B**, НО:
  - У UX435E один HDMI-выход 1.4 — он займётся под захват, и это HDMI 1.4 (1080p60 потолок).
  - CM489 на 1080p даёт 60 fps, но добавляет латентность захвата (~50-150 мс на UVC).
  - Тач при HDMI-варианте идёт ОТДЕЛЬНЫМ каналом (всё равно нужен ADB/сеть для ввода).
  - Вывод: HDMI годится для быстрой проверки «картинка вообще появляется», но как основной
    путь USB/ADB+QuickSync даст меньшую задержку.

### Что стоит подтвердить
- Точный вариант UX435E (UX435EA Iris Xe vs UX435EG +MX450) — на выбор энкодера не влияет
  (QuickSync есть в обоих), но влияет на запас производительности.
- Поддержку HEVC-энкода конкретным драйвером Intel на этой машине (Media Foundation покажет
  доступные MFT при инициализации — проверим в коде фазы 1).
